## Research dossier and upstream decisions

| Source | Decision | Reason |
|---|---|---|
| Android Developers, Offline-first data layer, `https://developer.android.com/topic/architecture/data-layer/offline-first` | ADAPT | Local source of truth and repository boundary are correct for standalone mobile; repository implementation remains Kimi-owned. |
| Android Developers, Data layer, `https://developer.android.com/topic/architecture/data-layer` | ADAPT | UI reads local repository state; network sources update local state rather than becoming UI truth. |
| Capacitor v8 Preferences, `https://capacitorjs.com/docs/apis/preferences` | RETAIN FOR LIGHTWEIGHT PREFS / REJECT FOR DOMAIN DATA | Official docs state Preferences is simple key/value storage and not a local database. No chat/model history or secrets go there. |
| WAI-ARIA APG Listbox, `https://www.w3.org/WAI/ARIA/apg/patterns/listbox/` | ADOPT | Provides exact roles, selection semantics and Arrow/Home/End keyboard contract for the themed model selector. |
| Capacitor v8 Keyboard, `https://capacitorjs.com/docs/apis/keyboard` | RETAIN | Existing pinned plugin owns keyboard visibility/resize integration; screen provides CSS containment and safe-area spacing. |
| Existing shadcn-vue 2.8.0 generated Button/Dialog/Drawer | ADOPT DIRECTLY | Already hash-conformance-gated by Kimi M1; no local lookalike or package addition. |
| Desktop provider SVG set | PORT BYTE-FOR-BYTE | Existing local assets keep provider identity identical and avoid mutable network assets. |
