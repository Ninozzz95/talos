              Per attrezzoCinque attrezzi hanno un cancello proprio · gli altri seguono la politica qui sopraIl permesso dell'attrezzo vince sulla politica della sessione
              
      
              
        
      
              
      
              
      
              Un «chiedi» su un attrezzo accende il canale di approvazione per tutta la sessione: finché resta acceso, TALOS chiede conferma anche per le altre azioni che lasciano traccia. È il limite del kernel di oggi, dichiarato invece che nascosto.
              
      
              
      
              I file di controllo (.claude/, package.json, gli hook) chiedono sempre una conferma singola, anche con «per questa sessione».
