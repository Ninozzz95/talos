Prova il flusso, non una figura.

Prototipo offline costruito sui token Calm scuro del repository Talos e sui contratti DOM della sidebar. La shell è ridotta; le nuove interazioni sono una proposta, non una build completa dell’app.

  1. Il bug di navigazione. Apri Agenti → un dettaglio → File → Agenti. Ritrovi lo stesso dettaglio senza bloccare le altre tab.
  2. File e contesto. Cerca, cambia la vista con Tutti i file e apri il menu ⋯. La selezione multipla è nelle Opzioni file; Spazio seleziona, Shift+F10 apre le azioni. Prova rinomina, duplica, cestina e ripristina.
  3. Da file ad agente. Premi il piccolo indicatore dell’agente accanto al file. Il diagramma apre quel nodo; il dettaglio contiene i file correlati.
  4. Il diagramma. Cambia ambito, cerca un agente, filtra lo stato, trascina il canvas, zooma, isola o collassa un ramo. Prova la timeline e l’affiancamento.
  5. Revisione. Da File seleziona un elemento, apri Azioni selezione (⋯) e scegli Refactor o Genera test. In Review prova il conflitto, la revisione, l’integrazione e lo scarto.
  6. Robustezza. Trascina il bordo della sidebar, oppure focalizzalo e usa le frecce. Prova gli stati in basso e passa fra sessioni.

Che cosa è simulato

Contenuti dei file, agenti, eventi, grafi, diff, esiti dei test e applicazione delle modifiche. Nessuna operazione modifica il filesystem o la repository. La ricerca AI/semantica è esplicitamente non collegata. I dati si azzerano ricaricando; soltanto la larghezza è ricordata quando il browser lo consente.

Identità e font

I colori, le famiglie tipografiche dichiarate, i raggi e le misure sono quelli del file index.css @13f65c15. I font non sono incorporati: se Instrument Sans e JetBrains Mono non sono installati, vengono usati i fallback. Non è una verifica pixel-per-pixel dell’app avviata.
