Registro dei processi

Il registro raccoglie i processi avviati durante una sessione e mostra l’ultimo evento ricevuto.

Riconoscere uno stallo
- Silenzio prolungato: nessun nuovo evento.
- Giri a vuoto: la stessa richiesta ripetuta senza progresso.
- Il processo resta disponibile per una decisione dell’utente.

Una segnalazione di stallo non termina il processo.

// Forgiato dal modello al giro 12, il 04/09. Nessuna scrittura, nessuna rete.
import { readdirSync, readFileSync, statSync } from 'node:fs';
import { join, extname } from 'node:path';

export function esegui({ cartella, salta = ['node_modules', '.git'] }) {
  const conta = {};
  (function scendi(dir) {
    for (const nome of readdirSync(dir)) {
      if (salta.includes(nome)) continue;
      const p = join(dir, nome);
      if (statSync(p).isDirectory()) { scendi(p); continue; }
      const est = extname(nome) || '(senza estensione)';
      conta[est] = (conta[est] ?? 0) + readFileSync(p, 'utf8').split('\n').length;
    }
  })(cartella);
  return conta;
}
