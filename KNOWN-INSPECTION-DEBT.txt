This package is an owner-inspection build, NOT a signed release.

The prior inspection packages were rejected and are not acceptance evidence.
Their known 47-error TypeScript state has been corrected in this snapshot.
A new inspection package is accepted for testing only if its Windows bootstrap
runs both typecheck and build with exit code 0. There is no longer any
"emit JavaScript despite TypeScript diagnostics" fallback.

The owner-reported infinite/long `starting` condition was reproduced as a
pre-provider checkpoint of the extracted inspection package itself. This
launcher now refuses package/project overlap before npm/build/runtime execution,
and the runtime checkpoint preflight fails oversized non-Git workspaces before
writing checkpoint blobs.

The TUI inspection snapshot also includes reactive terminal resize, structured terminal Markdown, and queue-preserving Esc interruption. Ctrl+C remains the aggressive cancel/clear control.\n\nDevelopment diagnostics are written to DEVELOPMENT-LOGS. On any FAIL send the
whole directory together with the checklist note.

This does not waive:
- full CI/release gates;
- M11-B signing/SBOM requirements;
- owner manual inspection;
- any competitive rating or release-ready gate.
